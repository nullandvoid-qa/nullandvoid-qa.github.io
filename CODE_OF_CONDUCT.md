# Code of Conduct

This project welcomes respectful, inclusive, and constructive participation.

## Expected behavior

- Be kind and professional in all interactions.
- Respect different experiences and viewpoints.
- Provide helpful, actionable feedback.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Trolling, disruptive behavior, or repeated disrespect.
- Sharing private information without consent.

## Reporting

Please report concerns to the project maintainers through GitHub issues or direct contact.
