# Template de Checklist de QA

## Pré-testes
- [ ] Requisitos e critérios de aceitação revisados.
- [ ] Ambiente configurado corretamente.
- [ ] Dados de teste disponíveis.

## Testes funcionais
- [ ] Fluxo principal validado.
- [ ] Cenários alternativos e de erro testados.
- [ ] Regras de negócio verificadas.

## Testes não-funcionais
- [ ] Acessibilidade básica verificada.
- [ ] Performance aceitável para cenários críticos.
- [ ] Segurança básica e dados sensíveis avaliados.

## Evidências
- [ ] Bugs registrados com passos e impacto.
- [ ] Capturas ou logs anexados quando necessário.
- [ ] Resumo de risco compartilhado com o time.
